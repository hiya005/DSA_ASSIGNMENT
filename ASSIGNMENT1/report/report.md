# Unit 1 Assignment Report

## Objective
To understand recursion, algorithm complexity, and problem-solving techniques.

---

## Factorial
Recursive implementation using base case.

Time: O(n)  
Space: O(n)

---

## Fibonacci

Naive:
- Time: O(2^n)
- Inefficient due to repeated calls

Memoized:
- Time: O(n)
- Uses extra space for caching

---

## Tower of Hanoi
- Recursive solution
- Moves = 2^n - 1
- Time: O(2^n)

---

## Binary Search
- Requires sorted array
- Time: O(log n)
- Recurrence: T(n) = T(n/2) + O(1)

---

## Conclusion
Recursion simplifies complex problems but can be inefficient without optimization.
