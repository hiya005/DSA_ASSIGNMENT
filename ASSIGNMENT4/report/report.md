# Unit 4 Assignment Report

## Objective
To implement non-linear data structures including BST, Graph, and Hash Table.

---

## BST
Implemented insert, search, delete, and inorder traversal.

- Inorder traversal produces sorted output.
- Deletion handled for:
  - Leaf node
  - One child
  - Two children

---

## Graph
Used adjacency list representation.

- BFS uses queue (level-order traversal)
- DFS uses recursion (depth-first)

Time Complexity:
O(V + E)

---

## Hash Table
Implemented separate chaining to handle collisions.

- Insert, Get, Delete operations tested
- Collisions demonstrated using same hash index

---

## Conclusion
Non-linear data structures efficiently handle hierarchical and network data.
Hashing provides fast lookup, while graphs and trees model real-world systems effectively.
